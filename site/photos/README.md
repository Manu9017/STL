# Product photos

Photos no longer go in this folder.

New photos go through the SHIVAS image library (kept off the public site): put the original files in
`originals/supplied/<item-id>/`, run `tools/pipeline.py`, approve the versions you want in
`registers/review.csv`, then rebuild `assets/library.js`. Approved pictures then appear on the item
pages and in the diagram previews automatically, each with its own stable ID.

The item ids and the angles to shoot are in the SHIVAS photo shot list.
