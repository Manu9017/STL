# SHIVAS website

Website for SHIVAS Technology Limited (wire drawing machines and hot-dip galvanizing plants) and sister company SHIVAS Reinplast (PP/FRP equipment, pickling, scrubbers, ETP and ZLD), Ghaziabad, India.

Plain HTML, CSS and JavaScript. No build step and no server code.

## Files

| Path | What it is |
|---|---|
| `index.html` | Main page: hot-dip galvanizing, with the SHIVAS Technology / SHIVAS Reinplast switch |
| `wire-drawing.html` | Separate page for wire drawing machinery |
| `3d-models.html` | Every 3D model on one page |
| `v/*.html` | The 3D model viewers, opened from 3d-models.html and the "3D models" sections |
| `v/img/*.jpg` | Preview pictures for the 3D models |

| `assets/library/` | The approved pictures in three sizes (preview, thumbnail, full) and the line drawings as SVG |
| `assets/preview.js`, `assets/preview.css` | The small picture card that appears when a machine in a diagram is pointed at, focused or tapped |
| `sitemap.xml`, `robots.txt` | Help search engines find every page |
| `photos/README.md` | How new photos get onto the site |
| `.nojekyll` | Tells GitHub Pages to serve the files as they are |

## Put it online with GitHub Pages

1. Create a new repository on GitHub, for example `shivas-website`.
2. Upload everything in this folder, keeping the `v` folder as it is. On the repository page choose **Add file → Upload files**, drag in the files and the `v` folder, then **Commit changes**.
3. Go to **Settings → Pages**. Under **Build and deployment**, set **Source** to **Deploy from a branch**, the branch to **main** and the folder to **/ (root)**, then **Save**.
4. After a minute or two the site is live at `https://<your-username>.github.io/shivas-website/`.

## Use your own domain (shivastechnology.com)

1. In **Settings → Pages → Custom domain**, enter `www.shivastechnology.com` and save. GitHub adds a `CNAME` file to the repository.
2. At your domain registrar, add a CNAME record: `www` → `<your-username>.github.io`.
3. For the bare domain `shivastechnology.com`, add A records pointing to `185.199.108.153`, `185.199.109.153`, `185.199.110.153` and `185.199.111.153`.
4. Back in **Settings → Pages**, tick **Enforce HTTPS** once the certificate is ready.

## Pictures and diagram previews

Pictures are not found by file name. `assets/library.js` lists each approved picture with an ID, and maps every machine in every production-line diagram (the wire flow strip, the numbered parts of the plant drawings, the stages of the wire lines and the line-ups on item pages) to one picture ID. Where no photo is approved yet, the machine's line drawing is shown. The file is generated by the SHIVAS image library tools from approved pictures only; do not edit it by hand.

## Editing

Open `index.html` or `wire-drawing.html` in any text editor. Both pages carry the same code; each shows only its own sections. Contact numbers, email and address are in the "Ask for a quote" section and the footer. Commit the change and GitHub Pages updates the site automatically.

The 3D models are indicative general arrangements; client names and commercial data have been removed.
