# SHIVAS Technology — website

Rebuild of shivastechnology.com: a gateway into two divisions, **Wire drawing** and **Hot dip galvanizing**.

- `CLAUDE.md` — the build brief. Start here.
- `design/` — approved page designs and the generator that holds all the copy.
- `assets/illustrations/` — 30 engineering-style SVG illustrations.
- `assets/logo/` — the SHIVAS logo: original and transparent cut-outs for light and dark grounds.
- `docs/` — redirect map, due-diligence findings and content checklist.

Regenerate the artboards with `python3 design/generator/build.py`.
